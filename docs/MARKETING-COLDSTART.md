# 冷启动营销作战包（2026-11-10）

## 一、先把问题说准

老板问的是"一个没有任何的盘子怎么让第一个人玩"。这不是营销问题，是**三笔成本**的问题：

| 第一个人的成本 | 具体是什么 | 现在能不能降 |
|---|---|---|
| 心理成本 | 怕被当成韭菜、怕规则看不懂 | 能（一屏说清 + 免费猜先表态） |
| 金钱成本 | 下注可能全亏，且盘面看着空 | 能（首注保险，见下） |
| 社交成本 | 群里发链接显得像广告 | 能（发的不是"来玩"，是"你怎么看"） |

**关于"假数据可以放上去"**：真正拦人的不是数字小，是数字**能被一眼核对**。basescan 上这个盘
总池 0 USDC，页面写 $12.5M TVL，任何懂行的人 10 秒就能截图发推特——第一个用户就是这么丢的。
所以这条路我不做；同样的"热闹感"用三个**真**信号就能拿到，而且更便宜：

1. **免费猜人数**（已上线）：`/api/guess` 服务端计数，卡片显示 `N picks · X yes / Y no`，
   没人时显示 `BE THE FIRST`——这是真话，也是唯一一句直接邀请读者动手的文案。
2. **AI 观点**（已上线）：每张卡有正方/反方两个 AI 的立场，写着 "2 agents took sides" 不需要编，
   它本来就是生成的。
3. **种子池**（待充值）：运营方真金放进池子，池子里有钱，赔率就不是 50/50 的摆设。

## 二、让第一个人下注：首注保险

**政策（写进页面，一句话）：前 100 个真实下注地址，若该笔最终亏损，运营方按亏损额补贴，单地址上限 $5。**

- 为什么有效：把"可能亏"变成"最多亏 0"，这是唯一能让陌生人在空盘上下第一注的东西。
- 为什么便宜：Base gas 可忽略，单笔上限 $5，100 人全亏 = $500，实际预期 $20–$50（因为一半人会赢）。
- 为什么诚实：它是**运营方补贴**，不是"稳赚"话术；链上能看到我们的转账，页面上写明上限和名额。
- 实现：`NEXT_PUBLIC_FIRST_BET_INSURANCE=5` 打开页面横幅；赔付走运营钱包 USDC 转账，凭证写进
  `docs/founding-bettors.md`（地址 + 首注 tx + 是否已补）。

## 三、种子流动性：让"第二个人"看到这里不是空的

第一个人的心理是"我先来"；第二个人的心理是"有人在"。空池会让第二个人的赔率是 50/50，
看起来像没人碰过。放种子以后：

- 池子里有真钱 → 赔率是真赔率（哪怕只有 2 USDC）；
- 卡片上 `totalNetPool > 0` → 走链上分支，显示的是合约余额，可查；
- 我们自己的种子仓位结算后照样领，不销毁、不特殊处理。

**成本表**

| 项目 | 数量 | 单价 | 合计 |

| 首注保险预算 | 上限 100 人 | ≤5 USDC | **≤500 USDC（先充 100）** |
| 合计建议充值 | | | **160 USDC + 0.01 ETH** |

## 六、判断标准（不做自嗨指标）

只看三个数，其余不看：

1. **免费猜转化**：首页 UV → 点了一次猜的比例（目标 ≥ 15%）
2. **首注转化**：猜过的人里，连钱包下注的比例（目标 ≥ 3%）
3. **回访**：结算后 48h 内回来看结果的比例（目标 ≥ 20%，免费猜天生带这个钩子）
