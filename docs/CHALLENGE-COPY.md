# 挑战文案（复制即用）

平台没有任何预算、没有投放、X 两个号都卡在平台风控里。能用的只有两件东西：**你自己的群**和
**别人已经在吵架的帖子**。这个文件解决第一件：把"来玩"换成"你敢押另一边吗"。

用法：挑一条，把链接里的 `?challenge=yes`（你押了 YES）或 `?challenge=no`（你押了 NO）留着，
发给一个群、一个朋友、或一条已经有争论的帖子下面。对方点开就是相反的一侧，已经选中，只剩签名。

---

1. 我押了「BTC 11 月 11 日收盘在 76,700 以上」。你敢押另一边吗？
   点进去选 NO 就行，链上结算，不用注册：
   https://predictionarena.online/market/725782832?challenge=yes

2. 这个盘我觉得会打脸大多数人：美联储 12 月不降息。我押 NO。
   你要是不同意，点这里直接押 YES（已选好）：
   https://predictionarena.online/markets?challenge=no

3. 赌一杯奶茶，ETH 这周站不上 2,250。我押了 NO。
   你来押 YES：https://predictionarena.online/market/726108314?challenge=no

4. 「203 个盘口，全部链上结算」这句话没什么用。有用的是这个：
   我今天押了 3 个，你想反驳哪个？https://predictionarena.online/markets

5. 有没有人敢跟我对赌 CPI？我押同比高于 2.4%。
   接的话点这里，选另一边就行：https://predictionarena.online/markets

## 发到哪里（按成功率排序）

| 位置 | 为什么有效 | 注意 |
|---|---|---|
| 你自己的群 / 朋友 | 对方认识你，点开率最高 | 一天最多 2 条，多了变广告 |
| 已有争论的推文 / Bluesky 帖 | 那里的人正在表达观点 | 只回复你在**答案上有分歧**的那种，不要贴到无关话题下 |
| Telegram 加密群 | 群里默认允许链接 | 先聊两句再发，直接甩链接会被踢 |
| Reddit r/CryptoCurrency 的日讨论帖 | 里面全是观点 | 需要账号；不要开新帖，只在评论里带 |

## 不要做的

- 不要一次把 10 条发到同一个群。发一条、等反应、再发下一条。
- 不要在别人的帖子下面只留链接 —— 先说一句你的判断，再给链接。
- 不要写"稳赚 / 必赢 / 内幕"。这个盘的卖点恰恰是"我们会把证据上链"。
